A static early-access concept page for connecting space-weather awareness with Earth modelling,
civilisation planning, disaster readiness and recovery thinking.

The current repository is a public-facing prototype, not an operational forecast service. It does
not ingest live observations, issue warnings or replace advice from official space-weather,
emergency-management or scientific agencies.

## What is here

- `index.html` is the single public page.
- `assets/` contains the page's images and supporting files.
- `LICENSE` records the reuse conditions.

## Use locally

Open `index.html` in a browser. No build step, account or backend is required.

Before using the concept for decisions, connect it to dated primary sources, show when each signal
was last checked, separate measured observations from models, and keep forecasts distinct from
speculative scenarios.
